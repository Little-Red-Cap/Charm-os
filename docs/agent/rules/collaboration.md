# Collaboration Rules

> **文档状态：`supporting`**

根 [`AGENTS.md`](../../../AGENTS.md) 负责仓库操作。本文件只补充决策升级、并行改动保护和证据沟通。

## 何时需要确认

只有以下情况需要暂停并让用户选择：

- 多条方案会改变公共接口、数据格式、兼容性或长期所有权；
- 操作具有不可逆风险，或会覆盖用户/并行任务的改动；
- 当前事实互相冲突，无法在源码和运行证据中裁决；
- 缺少外部凭据、硬件状态或产品决策，继续会产生伪实现。

普通可逆实现细节由 Agent 自行判断；需要提问时给出少量互斥选项、影响和推荐项。

## 并行工作区

- 目标文件出现并行变化时重新读取并合并意图，不能用旧快照覆盖；
- 不修改、暂存、提交或回退与任务无关的脏文件；
- 构建目录和设备可能被其它任务占用，删除、烧录或重启前先确认现场。

## 沟通与验证

- 中间更新报告正在核对的事实、变化和下一步动作；
- 完成说明列出实际验证和未执行部分；
- Host、QEMU、build-only 和真实板证据按各自覆盖范围表述，不扩大结论；
- 失败时保留日志和现场，说明失败阶段。

技术取舍见 [`embedded-modern-cpp.md`](embedded-modern-cpp.md)，架构审查见
[`charm-architecture.md`](charm-architecture.md)。
