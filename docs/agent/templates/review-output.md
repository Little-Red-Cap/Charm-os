# Review Output Template

本模板用于 Charm 项目中的代码审查输出。  
目标是让 review 输出保持：

- 结论清晰
- 优先级明确
- 判断有依据
- 建议可执行
- 不把“看起来还行”当作 review

相关文件：
- `../skills/code-review/SKILL.md`
- `../skills/code-review/checklist.md`
- `../skills/code-review/examples.md`

# 模板

## 总体结论
<一句话总结当前 review 结论。>

可选表达：
- 存在阻断问题，不建议合并。
- 总体方向正确，但有若干重要问题需要修正。
- 未发现阻断问题，可以继续推进，但仍有优化空间。
- 当前信息不足，暂不能做完整判断，但已发现若干风险点。
