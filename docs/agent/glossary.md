# Charm Agent Glossary

> status: `supporting`
>
> 本页只解释 Agent 文档自身用语，不定义 Charm Core 或公共 API。

- **Route**：按任务选择最短阅读路径。
- **Rule**：跨任务生效的操作或工程约束。
- **Skill**：某类任务的检查和执行方法。
- **Template**：可选输出骨架，不携带架构裁决。
- **Evidence domain**：Host、QEMU、真实板或 build-only 等证据适用范围。

Capability Contract、Requirement、Provision、Binding 和裁决等级以
[`CONSTITUTION.md`](../../CONSTITUTION.md) 与
[`charm_core_contract.md`](../architecture/charm_core_contract.md) 为准。本页不复述实现名词，也不能替代
源码、CMake、测试或运行证据。
