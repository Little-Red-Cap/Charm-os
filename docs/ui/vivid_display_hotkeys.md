# Vivid Display Hotkeys

These keys only affect the active display mode:

- BW1: `,` / `.` adjust threshold
- Gray2: `[` / `]` adjust strength, `G` cycles curve (linear/soft/contrast)
- E-ink: `1/2` adjust partial ratio, `3/4` adjust max partial count, `5/6` adjust min full interval (ms)

Notes:
 - The hotkeys are only active in interactive runs (not headless `--soa-ci`).
 - Use `--bw1`, `--gray2`, or `--eink` to select the display mode.
