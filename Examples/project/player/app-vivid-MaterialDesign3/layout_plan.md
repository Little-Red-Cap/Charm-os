# 布局规划（Home / NowPlaying / Library）

本页用结构化方式规划三大主屏的组件层级与区域划分，指导 UI 落地。

## Home
- 顶部：标题区（主标题 + 副标题）
- 中部：封面拼贴（圆形/圆角）
- 底部：迷你播放条
- 最底：导航栏（Home/Search/Library）

## Now Playing
- 顶部：返回/更多操作
- 中部：大封面 + 标题/作者
- 下部：进度条 + 时间
- 底部：播放控制（上一首/播放/下一首）
- 最底：迷你播放条可隐藏

## Library
- 顶部：标题 + tabs（Songs/Albums/Artists）
- 中部：列表（卡片化条目）
- 底部：迷你播放条
- 最底：导航栏
