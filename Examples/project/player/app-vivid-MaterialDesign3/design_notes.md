# 设计参考与提炼（PixelPlayer）

本页记录从 PixelPlayer 提炼的布局/配色/排版要点，作为 Material Design 3 变体的设计依据。

## 视觉语言
- 深色基底 + 低饱和主题色，整体偏柔和
- 圆角显著（卡片/按钮/列表）
- 留白较大，节奏感强
- 统一胶囊/圆角矩形语言

## 布局提炼
### Home
- 大标题 + 小副标题（强字号对比）
- 圆形封面拼贴作为视觉主体
- 底部固定迷你播放条 + 导航栏

### Now Playing
- 大封面居中
- 标题/作者居中
- 进度条居中
- 三段式播放控制

### Library
- 顶部标题 + tabs
- 列表卡片化，封面占位较大
- 底部仍保留迷你播放条

## 风格对齐要点
- 圆角：按钮/卡片保持更大半径
- 字重：标题偏粗、正文偏细
- 颜色：强调色来自封面或主题色
