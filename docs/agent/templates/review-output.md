# Review Output Template

> status: `supporting`
>
> 可选模板。没有对应内容时省略该段，不填充套话。

## Findings

按严重性排列。每项包含：文件与行号、可复现问题、行为影响、修复方向。

## Open Questions

只列会改变结论的问题或假设。

## Verification Gaps

列出未运行测试、缺失平台证据和残余风险。

## Summary

用一段话说明是否存在阻断问题；findings 仍是主要内容。

详细检查见 [`code-review skill`](../skills/code-review/SKILL.md) 和
[`checklist`](../skills/code-review/checklist.md)。
