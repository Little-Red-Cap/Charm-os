# 示例 1：新增能力模块骨架

## 输入场景
用户请求：

> 新增一个 I2C 设备抽象能力。

## 参考输出结构

### 设计说明
- 能力定义放在 IO 层
- 通过 `init.graph` 装配
- 接口使用强类型句柄与 `std::span`

### 代码草案
- `io.i2c` 模块
- `driver.i2c_channel` 适配层
- `board_caps` 注入

### 风险与未决点
- I2C 速率配置策略
- ISR 安全约束

# 示例 2：需求不清，先讨论方案

## 输入场景
用户请求：

> 增加“日志持久化”能力。

## 参考输出

### 需要澄清
- 日志保存位置（Flash/SD/外部存储）
- 是否实时路径
- 最大容量与覆盖策略

### 候选方案
1) 环形块设备日志
2) 文件系统日志

### 取舍建议
- 若实时要求高：倾向环形块设备
- 若调试优先：倾向文件系统
