## 先不要做什么

- 不要制造第二份 Constitution、核心契约或主题首页。
- 不要让旧 roadmap、v0 或多战线快照继续冒充 canonical 入口。
- 不要一开始批量重写 supporting / exploration 正文；先修状态和路由。
- 不要让坏链接、循环定义或冲突定位留在默认阅读路径。

## 完成前自检

- canonical 入口是否只给出同一个 Charm 定位。
- 文档是否明确标为 canonical、supporting、exploration 或 archive。
- supporting 文档是否只在自身范围内主张权威。
- exploration 文档是否回链 Constitution 与核心契约。
- 本地 Markdown 链接是否有效。
