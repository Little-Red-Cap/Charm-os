# Dev Loader Packet Stream Smoke

Host-only smoke for the Dev Loader packet stream prototype.

It proves that payload bytes can be encoded as a raw packet v0 stream and
replayed through `PacketRuntime -> BinaryReceiveRuntime` without defining a
second receive state machine.

```powershell
cmake -S Examples/system/dev_loader_packet_stream_smoke -B Examples/system/dev_loader_packet_stream_smoke/cmake-build-dev-loader-packet-stream-smoke -G Ninja -DCMAKE_CXX_COMPILER="D:/Toolchains/w64devkit/bin/g++.exe"
cmake --build Examples/system/dev_loader_packet_stream_smoke/cmake-build-dev-loader-packet-stream-smoke
ctest --test-dir Examples/system/dev_loader_packet_stream_smoke/cmake-build-dev-loader-packet-stream-smoke --output-on-failure
```

It can also replay a packet stream generated by
`Examples/system/dev_loader_packet_stream_tool`:

```powershell
Examples/system/dev_loader_packet_stream_smoke/cmake-build-dev-loader-packet-stream-smoke/dev-loader-packet-stream-smoke.exe path/to/input.packetstream
```

This is not a USB framing layer, retry policy, or product update protocol.
