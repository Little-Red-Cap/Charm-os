# 硬规则与禁区（rules）

## 协作硬规则
- 只使用中文沟通与提交信息
- 先构建再提交（除非明确允许跳过）
- 分批提交，小步快照
- 不修改不相关文件
- 发现意外改动必须立即停下并报告

## 架构禁区
- 协议层禁止 busy-spin/自带超时循环
- Channel 禁止 Ok(0)
- 禁止隐式全局入口，必须 Context/Registry 注入
- 未注册能力禁止直接 init
- protocol/io/at 等层禁止依赖 platform/hal
- 核心库禁止依赖 std::chrono（仅 PC 侧允许）

## 构建与验证
- Win stub 优先用于逻辑验证
- MCU 构建仅用于编译与链路检查，逻辑验证需明确说明

## 文档与命名
- 新增能力必须更新相关文档索引
- capability 命名稳定，不随意改名
