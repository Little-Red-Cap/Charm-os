# 统一提示模板（prompts）

> 目的：让协作者在不同场景下保持一致的沟通方式与输出质量。

## 基础模板（推荐）
- 目标：清晰描述要解决的问题与期望结果
- 约束：平台/环境/禁用项/性能边界
- 输入：路径、接口、样例数据、错误日志
- 输出：需要的文件/命令/提交策略

## 示例
```
目标：为现有模块补充失败诊断。
约束：不改变公共接口；复用现有构建目录。
输入：模块路径、复现命令和错误日志。
输出：改动文件、验证结果和提交范围。
```

## 变更级别说明
- 小改动：直接执行并汇报结果
- 中改动：先给方案与文件范围
- 大改动：先评审方案，再落地

## 反馈模板
- 现象：
- 复现：
- 期望：
- 约束：
- 相关日志/路径：

## 对话约定
- 重要约束必须先说明
- 变更较大时要求先给方案再落地
- 构建/测试要求明确说明（是否必须）
