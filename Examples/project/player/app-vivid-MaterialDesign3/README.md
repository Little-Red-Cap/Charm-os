# Player UI - Material Design 3

本目录为播放器的 **Material Design 3 风格 UI 变体**。目标是仅替换界面与视觉语言，不改动 `app-common` 的后端/文件系统/播放逻辑。

## 设计方向（第一阶段）
- 深色基底 + 低饱和主题色，强调“柔和对比”
- 更大的圆角与更厚的留白
- 按钮与列表统一“胶囊/圆角矩形”语言

## 说明
- 模块名仍为 `player.ui` / `player.ui_builder`，通过独立 target 编译避免与旧 UI 冲突
- 仅调整 UI 与主题，不影响控制面/数据面

## 文档
- `design_notes.md`：设计参考与提炼
- `layout_plan.md`：三大主屏布局规划
- `todo.md`：推进清单


# 设计参考与提炼（PixelPlayer）

本页记录从 PixelPlayer 提炼的布局/配色/排版要点，作为 Material Design 3 变体的设计依据。

## 视觉语言
- 深色基底 + 低饱和主题色，整体偏柔和
- 圆角显著（卡片/按钮/列表）
- 留白较大，节奏感强
- 统一胶囊/圆角矩形语言

## 布局提炼
### Home
- 大标题 + 小副标题（强字号对比）
- 圆形封面拼贴作为视觉主体
- 底部固定迷你播放条 + 导航栏

### Now Playing
- 大封面居中
- 标题/作者居中
- 进度条居中
- 三段式播放控制

### Library
- 顶部标题 + tabs
- 列表卡片化，封面占位较大
- 底部仍保留迷你播放条

## 风格对齐要点
- 圆角：按钮/卡片保持更大半径
- 字重：标题偏粗、正文偏细
- 颜色：强调色来自封面或主题色



# 布局规划（Home / NowPlaying / Library）

本页用结构化方式规划三大主屏的组件层级与区域划分，指导 UI 落地。

## Home
- 顶部：标题区（主标题 + 副标题）
- 中部：封面拼贴（圆形/圆角）
- 底部：迷你播放条
- 最底：导航栏（Home/Search/Library）

## Now Playing
- 顶部：返回/更多操作
- 中部：大封面 + 标题/作者
- 下部：进度条 + 时间
- 底部：播放控制（上一首/播放/下一首）
- 最底：迷你播放条可隐藏

## Library
- 顶部：标题 + tabs（Songs/Albums/Artists）
- 中部：列表（卡片化条目）
- 底部：迷你播放条
- 最底：导航栏
